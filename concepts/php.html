쉽게 말하면

반찬가게에 미리 만들어 둔 도시락을 집어 가는 것과, 주문을 받고 그때부터 요리해 내보내는 것의 차이예요. 앞은 누구에게나 똑같은 페이지, 뒤가 PHP가 하는 일이에요. 누가 들어왔는지, 장바구니에 뭐가 있는지에 따라 사람마다 다른 페이지를 그 자리에서 지어 보내요.

웹이 막 퍼지던 시절부터 쓰여서 지금도 세상의 수많은 사이트가 PHP로 돌아가요. 블로그와 홈페이지를 만드는 WordPress가 대표적이고요. JavaScript가 브라우저 쪽에서 움직임을 맡는다면, PHP는 서버 쪽에서 내용을 만드는 일을 맡아요.

브라우저는 그리기만 해요

1요청이 오면 서버가 PHP 파일을 그때 실행해요. 미리 만들어 둔 파일을 꺼내 주는 게 아니에요.

2PHP는 필요하면 데이터베이스에서 값을 꺼내 와 글자 사이사이에 끼워 넣고 HTML을 한 장 조립해요.

3브라우저에는 완성된 결과만 가요. PHP 코드 자체는 넘어가지 않아서, 사용자가 들여다볼 수 없어요. 브라우저에서 도는 JavaScript와 가장 다른 점이에요.

3

직접 해보기

PHP가 깔려 있다면 파일 하나와 명령 한 줄로 바로 확인할 수 있어요.

index.php

<?php
$name = "하늘";
echo "<h1>안녕하세요, {$name}님</h1>";
echo "<p>지금은 " . date("H:i") . "입니다</p>";

터미널

$ php -S localhost:8000
# 브라우저에서 http://localhost:8000 을 열면
# 새로고침할 때마다 시각이 바뀌어요

브라우저에서 페이지 소스 보기를 해 보면 <?php는 보이지 않고 결과인 <h1>만 보여요. 서버에서 이미 다 처리되고 결과만 건너왔다는 뜻이에요. Next.js가 하는 서버 렌더링도 발상은 같아요 — 쓰는 언어와 시대가 다를 뿐이에요.
