후처리 · postprocessing · 後処理

후처리는 본 작업이 내놓은 결과를 받는 쪽이 쓸 수 있는 모양으로 다듬는 단계예요. 결과가 나왔다고 일이 끝난 건 아니에요.

데이터도 그래요. 계산이 끝나면 0.9231… 같은 숫자 뭉치가 남는데, 이걸 그대로 보고서에 붙일 수는 없어요. 기준에 못 미치는 것을 걸러내고, 반올림하고, 보기 좋은 모양으로 바꿔 사람이나 다음 시스템에 넘겨요. 이 마무리가 후처리예요. 전처리의 짝이에요.

사람이 읽거나 다음 시스템이 받아요

01걸러내기

기준(임계값)에 못 미치는 결과를 빼요.

02다듬기

반올림하고, 자릿수와 순서를 맞춰요.

03보기 좋게

0.92를 92%로, 1250000을 1,250,000원으로 바꿔요.

04내보내기

파일·표·화면 등 받는 쪽이 읽는 형태로 저장해요.

1먼저 받는 쪽이 무엇을 기대하는지 정해요. 사람이 읽을 보고서인지, 다른 프로그램이 받을 파일인지에 따라 다듬는 방향이 달라져요.

2거르기를 먼저, 꾸미기를 나중에 해요. 숫자를 "92%" 같은 글자로 바꾸고 나면 더는 크기를 비교하거나 계산할 수 없어요.

3본 작업의 결과는 건드리지 않고 따로 남겨 둬요. 꾸민 것만 남기면, 나중에 기준을 바꾸고 싶을 때 처음부터 다시 돌려야 해요.

3

직접 해보기

추천 점수가 나왔다고 해 볼게요. 0.7 넘는 것만 골라, 사람이 읽는 모양으로 바꿔 내보내요.

main.py

import pandas as pd

scores = pd.DataFrame({"메뉴": ["라떼", "아메리카노", "치즈케이크", "녹차"],
                       "추천점수": [0.92, 0.71, 0.48, 0.355]})

top = scores[scores["추천점수"] >= 0.7].copy()        # 1. 거르기
top = top.sort_values("추천점수", ascending=False)     # 2. 줄 세우기
top["추천점수"] = (top["추천점수"] * 100).round().astype(int).astype(str) + "%"
print(top.to_string(index=False))                     # 3. 보기 좋게

출력

   메뉴 추천점수
   라떼  92%
아메리카노  71%

main.py (이어서)

sales = pd.DataFrame({"메뉴": ["라떼", "아메리카노"], "합계": [1250000, 480000]})
sales["합계"] = sales["합계"].map(lambda v: f"{v:,}원")   # 1,250,000원
sales.to_csv("report.csv", index=False, encoding="utf-8-sig")   # 4. 내보내기

utf-8-sig는 엑셀에서 한글이 깨지지 않게 표시를 붙여 저장하라는 뜻이에요. 받는 쪽이 엑셀이라면 이것도 후처리의 일부예요.

상황 1 · 후처리로 덮으면 안 되는 것

결과가 이상할 때 후처리에서 이상한 값만 빼 버리고 넘기고 싶어져요. 하지만 그건 본 작업이나 전처리가 틀렸다는 신호인 경우가 많아요. 후처리는 모양을 바꾸는 자리지, 틀린 것을 가리는 자리가 아니에요.

상황 2 · 뒷정리라는 뜻으로도 써요

프로그램에서 "후처리"라고 하면 쓰고 난 것을 정리하는 일을 가리키기도 해요. 열어 둔 파일 닫기, 임시 파일 지우기, 연결 끊기 같은 것들이죠. 파이썬의 with 블록이나 finally가 이 일을 맡아, 도중에 오류가 나도 정리는 하게 해 줘요.

상황 3 · 그림과 영상에서도 같은 말

게임이나 영상에서 다 그린 화면에 빛 번짐·흐림 같은 효과를 얹는 것도 후처리(post-processing)라고 해요. 본 작업이 끝난 결과물에 마지막 손질을 더한다는 점에서 뜻이 같아요.

한 줄 정리

결과가 나온 뒤, 받는 쪽이 쓸 수 있는 모양으로.
