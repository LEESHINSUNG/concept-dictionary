서버

server · 서비스를 주는 쪽

서버는 요청을 받아 처리해 주는 쪽이에요. 특별한 기계의 이름이 아니라 맡은 역할의 이름이에요.

작성일 2026-10-21 카테고리 네트워크 › 기초 개념

1

쉽게 말하면

식당의 주방을 떠올려 보세요. 주방은 손님을 찾아다니지 않아요. 가만히 있다가 주문이 들어오면 만들어 내보내죠. 서버가 딱 그래요. 늘 켜진 채로 요청이 오기를 기다리다가, 오면 처리해서 돌려줘요.

영어 serve가 '시중들다, 내어 주다'라는 뜻이에요. 그래서 서버는 비싼 기계를 가리키는 말이 아니에요. 내 노트북도 그 역할을 맡기면 그 순간 서버예요. 데이터센터에 줄지어 선 기계들은 그 역할을 24시간 안정적으로 하려고 그렇게 생겼을 뿐이에요.

1서버는 먼저 말을 걸지 않아요. 켜 둔 채로 기다리는 게 일이고, 두드리는 쪽은 클라이언트예요. 그래서 찾아올 수 있도록 주소가 고정돼 있어야 해요.

2요청이 오면 필요한 걸 찾거나 계산해서 결과를 만들어요. 데이터베이스에 묻기도 하고요.

3결과만 돌려주고 다시 기다려요. 요청 수천 개가 한꺼번에 오면 줄이 밀리는데, 이걸 일부러 일으키는 공격이 DDoS예요.

3

직접 해보기

파이썬 한 줄이면 내 컴퓨터가 바로 웹 서버가 돼요.

터미널

$ python3 -m http.server 8000
Serving HTTP on :: port 8000 ...
# 브라우저에서 http://localhost:8000 으로 들어가 보세요
# 끝낼 때는 Ctrl+C

이 명령을 켜 둔 동안에는 그 폴더의 파일을 누구에게나 내어 주는 상태가 돼요. 같은 LAN에 있는 사람은 내 주소로 들어올 수 있으니, 확인이 끝나면 꺼 두는 게 좋아요.
