TypeScript

타입스크립트 · TS

TypeScript는 JavaScript에 "이 값은 숫자, 저 값은 글자"라는 표시를 더한 언어예요. 실행하기 전에 실수를 미리 잡아 줘요.

작성일 2026-10-22 카테고리 웹 › 프로그래밍 언어

1

쉽게 말하면

택배 상자에 "깨지는 물건", "위로 향하게" 같은 표시를 붙이는 일과 같아요. 표시가 없어도 배송은 되지만, 붙여 두면 다루는 사람이 실수하기 전에 알아차리죠.

JavaScript는 자유로워요. 숫자가 들어갈 자리에 글자를 넣어도 일단 돌아가요. 편하지만 잘못된 걸 한참 뒤에야 알게 된다는 게 문제죠. TypeScript는 그 자리에 미리 "여긴 숫자" 같은 표시를 달게 해요. 그러면 코드를 적는 그 순간 편집기가 빨간 줄로 알려 줘요. 사용자가 쓰다가 터지는 대신에요.

1값마다 어떤 종류인지 적어 둬요. 안 적어도 TypeScript가 짐작해 주는 경우가 많아요.

2어긋난 곳이 있으면 실행하기 전에 알려 줘요. 이름을 잘못 친 것, 있을 수도 없을 수도 있는 값을 그냥 쓴 것 같은 흔한 실수가 여기서 걸려요.

3검사가 끝나면 타입 표시는 전부 떼어내고 평범한 JavaScript로 바꿔 내보내요. 브라우저는 TypeScript를 모르거든요.

3

직접 해보기

같은 함수를 두 언어로 적어 보면 차이가 한눈에 보여요.

price.ts

function total(price: number, count: number): number {
  return price * count;
}

total(1000, 3);      // 3000
total(1000, "3");    // 여기서 바로 빨간 줄이 그어져요

JavaScript였다면

같은 코드를 JavaScript로 적으면 total(1000, "3")도 그냥 돌아가요. 결과는 3000이 나오기도 하고 "10001000..." 같은 엉뚱한 글자가 되기도 해요. 터지지 않고 조용히 틀린다는 게 더 무서운 부분이에요.

TypeScript 파일은 그대로는 실행되지 않아요. 다만 Next.js 같은 도구에는 변환 과정이 이미 들어 있어서, 요즘은 그냥 .ts로 적고 바로 쓰는 경우가 많아요.
