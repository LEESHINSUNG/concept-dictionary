CSS

씨에스에스 · Cascading Style Sheets

CSS는 HTML로 세운 뼈대에 모양을 입히는 언어예요. 어떤 요소를 골라서, 어떻게 보이게 할지를 적어요.

작성일 2026-10-22 카테고리 웹 › 스타일

1

쉽게 말하면

같은 골조의 집이라도 벽지와 조명을 바꾸면 전혀 다른 집이 되죠. CSS가 그 인테리어예요. HTML은 그대로 두고 CSS만 갈아 끼워도 사이트 분위기가 통째로 바뀌어요.

적는 방식은 늘 똑같아요. 무엇을 고를지(선택자)와 어떻게 할지(속성과 값) 두 가지예요. "모든 제목을 파랗게", "이 버튼만 둥글게" 같은 식이죠. 이름 앞의 Cascading은 '폭포처럼 흘러내린다'는 뜻인데, 여러 규칙이 같은 요소에 겹칠 때 정해진 순서대로 흘러 최종 모습이 정해진다는 의미예요.

같은 글, 다른 모습

1선택자로 대상을 골라요. 태그 이름(p), 지정한 이름(.card) 등으로 고를 수 있어요.

2고른 대상에 속성과 값을 줘요. HTML은 한 글자도 바뀌지 않아요. 보이는 방식만 달라져요.

3한 요소에 여러 규칙이 걸리면 더 구체적으로 고른 쪽이, 구체성이 같으면 나중에 적힌 쪽이 이겨요. 이게 Cascading이에요.

3

직접 해보기

HTML 파일 안에 <style> 한 덩어리만 넣어도 바로 적용돼요.

style 부분

h1 {
  color: #1F5FD0;      /* 모든 h1을 파랗게 */
  font-size: 40px;
}

.warn {
  background: #FFE98A;  /* class="warn"인 것만 노랗게 */
}

왜 따로 떼어 놓을까

태그마다 모양을 적을 수도 있지만, 그러면 색 하나 바꾸는 데 파일 수십 개를 고쳐야 해요. CSS 파일 하나로 모아 두면 한 줄만 고쳐도 사이트 전체가 바뀌어요. 이 사전도 assets/css/style.css 한 파일이 모든 페이지의 모양을 맡고 있어요.

요즘 CSS는 꾸미기를 넘어 화면 크기에 따라 배치를 바꾸는 일까지 해요. 이 사전이 휴대폰에서는 세로로, PC에서는 가로로 늘어서는 것도 CSS가 하는 일이에요.
