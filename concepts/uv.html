uv

유브이 · Astral이 만든 도구

uv는 파이썬 프로젝트에서 패키지 설치·가상환경·파이썬 버전을 혼자 다 맡는 도구예요. Rust로 만들어서 기존 도구보다 훨씬 빨라요.

쉽게 말하면

예전에는 카메라, 지도책, MP3 플레이어를 따로 들고 다녔죠. 스마트폰 하나가 그걸 전부 대신하게 됐고요. uv는 파이썬 쪽의 스마트폰 같은 도구예요.

지금까지는 패키지를 설치할 땐 pip, 프로젝트마다 공간을 나눌 땐 venv, 파이썬 버전을 바꿀 땐 pyenv를 따로 썼어요. uv는 이 일들을 한 명령으로 묶어서 처리해요. 공식 문서에서는 pip보다 10~100배 빠르다고 소개하고 있어요.

가상환경을 켜지 않아도 돼요

1uv add requests라고 하면 필요한 패키지가 pyproject.toml에 적혀요.

2uv가 PyPI 창고에서 내려받아 프로젝트 폴더의 .venv에 넣고, 정확한 버전을 uv.lock에 남겨요.

3uv run으로 실행하면 그 가상환경을 알아서 써요. 따로 켜는 과정이 없어요.

3

직접 해보기

새 프로젝트를 만들고, 패키지를 더하고, 실행하는 데까지 네 줄이면 돼요.

터미널

$ uv init myapp     # 새 프로젝트 폴더를 만들어요
$ cd myapp
$ uv add requests    # 받아서 .venv에 넣고 기록까지 해요
$ uv run main.py     # 가상환경을 켜지 않고 바로 실행해요

uv 자체를 설치하는 방법은 공식 문서(docs.astral.sh/uv)의 안내를 따라요. 출력은 환경마다 조금 달라요.
