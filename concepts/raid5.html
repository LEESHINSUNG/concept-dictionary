RAID 5

레이드 5 · RAID 5 · 분산 패리티 · distributed parity

RAID 5는 데이터를 여러 디스크에 나눠 쓰면서, 복구용 정보를 모든 디스크에 골고루 흩어 두는 방식이에요. 하나가 망가져도 나머지로 되살려요.

작성일 2026-11-05 카테고리 품질관리 › 신뢰성

1

쉽게 말하면

친구 셋이 각자 숫자를 하나씩 외우고 있어요. 그리고 네 번째 친구가 "셋을 더하면 짝수"라는 쪽지를 들고 있다고 해 볼게요. 이제 누구 하나가 숫자를 잊어버려도 괜찮아요. 남은 둘의 숫자와 쪽지를 보면 잊은 숫자를 계산해 낼 수 있거든요.

RAID 5가 정확히 이거예요. 데이터를 여러 디스크에 나눠 쓰면서, 되살리기 위한 정보(패리티)를 함께 적어 둬요. 디스크 하나가 통째로 망가져도 나머지 디스크로 그 내용을 다시 만들어 낼 수 있어요.

특이한 점은 패리티를 한 디스크에 몰아 두지 않는다는 거예요. 줄마다 다른 디스크에 흩어 놓아요. 한 곳에 몰면 거기만 계속 바빠져서 전체가 느려지거든요.

최소 디스크

3개 (보통 4개 이상)

견디는 고장

한 개까지

쓸 수 있는 용량

디스크 수 − 1개분

디스크가 넷이면 한 줄은 데이터 셋 + 패리티 하나예요. 그래서 쓸 수 있는 용량이 네 개 중 세 개분이 돼요.

01하나까지만 견뎌요

한 개가 망가지면 나머지로 되살려요. 그런데 두 개가 동시에 망가지면 계산할 근거가 사라져서 못 살려요.

02쓰기가 느려요

값 하나를 고쳐도 패리티까지 다시 계산해 적어야 해요. 읽기는 빠르지만 쓰기는 손해를 봐요.

03되살리는 동안이 위험해요

망가진 디스크를 새것으로 갈면 나머지를 전부 읽어 내용을 다시 만들어요. 이때 디스크들이 가장 혹사당해서, 그 와중에 또 하나가 망가지는 일이 실제로 일어나요.

04둘까지 견디려면

패리티를 두 벌 두는 RAID 6을 써요. 용량을 하나 더 내주는 대신 두 개까지 견뎌요. 디스크가 크고 많을수록 이쪽을 고르는 경우가 늘었어요.

1패리티는 어려운 계산이 아니에요. 세로로 1의 개수가 짝수가 되게 한 자리를 더 적어 두는 것뿐이에요.

2그래서 되살리기도 같은 방법이에요. 사라진 자리에 무엇이 있어야 짝수가 되는지를 거꾸로 계산해요.

3중요한 건 RAID는 백업이 아니라는 것이에요. 디스크 고장은 막아 주지만, 실수로 지운 파일이나 랜섬웨어에 당한 파일은 패리티까지 똑같이 망가져요.

예시로 보기

패리티로 되살리는 원리

              1열  2열  3열  4열
디스크1        1    0    1    1
디스크2        0    1    1    0
디스크3        1    1    1    1
----------------------------------
패리티         0    0    1    0    ← 세로로 1의 개수가 짝수가 되게

디스크2가 통째로 망가졌다면?

1열: 1 + ? + 1 과 패리티 0  →  이미 짝수이니 ? = 0
2열: 0 + ? + 1 과 패리티 0  →  홀수를 짝수로 만들려면 ? = 1
3열: 1 + ? + 1 과 패리티 1  →  패리티까지 합쳐 짝수여야 하니 ? = 1
4열: 1 + ? + 1 과 패리티 0  →  이미 짝수이니 ? = 0

되살린 디스크2 : 0  1  1  0      원래 값과 같아요

용량은 얼마나 줄어드나

디스크 4개를 묶으면 3개분만 쓸 수 있어요. 5개면 4개분, 10개면 9개분이에요. 묶는 개수가 많을수록 손해 보는 비율이 줄어요. 다만 개수가 많아질수록 그중 하나가 망가질 확률도 같이 올라가니, 무작정 늘리지는 않아요.

미러링과 견주면

미러링(RAID 1)은 똑같이 두 장 적어요. 용량이 절반으로 줄지만 되살릴 게 없어요. 멀쩡한 쪽을 그냥 읽으면 되니까요. RAID 5는 용량 손해가 적은 대신 계산이 필요해요. 용량을 아낄지, 단순함을 택할지의 차이예요.

고장 난 채로 돌아가는 상태를 그냥 두면 안 돼요. 하나가 망가진 RAID 5는 더 이상 여유가 없는 상태예요. 그래서 예비 디스크를 미리 꽂아 두고 자동으로 갈아 끼우게 해 두는 일이 많아요.

한 줄 정리

하나가 빠져도, 나머지가 그 자리를 계산해 내요.
